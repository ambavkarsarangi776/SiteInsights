Web Performance Glossary

A beginner-friendly guide to Core Web Vitals, performance thresholds, and what your doctor's report means.

🎯 Doctor’s Performance Scoring Criteria

Website Speed Doctor uses Google Lighthouse's weighted performance algorithm. The overall score represents how fast, responsive, and stable your site feels to real visitors. Here is the exact scoring criteria and doctor's diagnostic status:

90 to 100

🟢 Excellent

Your page loads fast and meets Google’s recommended performance targets.

70 to 89

🟡 Good

Healthy overall. A few fixes would make it noticeably snappier.

50 to 69

🟠 Needs Work

Usable, but visitors on slower mobile networks will notice delays. Fix the top issues.

0 to 49

🔴 Poor

Serious speed problems are likely to frustrate visitors. Fix the top issues first.

📖 The 5 Key Speed Metrics Explained

1. First Contentful Paint (FCP)

Target: ≤ 1.8 s

What it measures: The exact time from when the user enters your URL until the browser renders the very first piece of content (text, an image, or canvas element).

Plain English: The "is it working?" moment. If FCP is fast, visitors know the server is alive and responding quickly.

2. Largest Contentful Paint (LCP)

Target: ≤ 2.5 s

What it measures: The time it takes for the largest visual block of content on the screen to appear (e.g. hero banner image, heading, or primary body paragraph).

Plain English: The "is it useful?" moment. This is what users actually came to see. Google treats LCP as a primary Core Web Vital.

3. Total Blocking Time (TBT)

Target: ≤ 200 ms

What it measures: The total time during page load where the browser's main thread is locked up by heavy JavaScript execution, preventing user interactions.

Plain English: The "is it responsive?" metric. High TBT causes buttons and menus to feel frozen when clicked.

4. Cumulative Layout Shift (CLS)

Target: ≤ 0.1

What it measures: How much elements unexpectedly jump or shift position while the page is rendering (often caused by images without width/height attributes or late-loading web fonts and ads).

Plain English: Visual stability. Low CLS ensures buttons don't move right before a visitor clicks on them.

5. Speed Index

Target: ≤ 3.4 s

What it measures: How quickly the visible area of the page fills with content over time.

Plain English: A smooth progressive reveal where parts of the page appear continuously feels much faster to human brains than a blank screen that flashes all at once.

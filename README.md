# Website Speed Doctor

Website Speed Doctor is a web application where users paste a website URL and receive a plain-English performance report: an overall score, Core Web Vitals, and a prioritized list of beginner-friendly fixes.

It leverages the Google PageSpeed Insights API (running Lighthouse) and stores scan histories in MySQL.

## Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+), Chart.js
- **Backend**: Node.js with Express
- **Database**: MySQL 8 (`mysql2` promise API)
- **External API**: Google PageSpeed Insights API v5
